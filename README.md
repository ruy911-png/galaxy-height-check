# 높이 보기 — 갤럭시 한 화면 높이 계산 시험용 v0.3.0

가구가 가리지 않는 벽 쪽으로 **실제 바닥과 천장을 한 화면에 담으면**, 위·아래의 실제 WebXR 표면 위치로 수직 높이를 자동 계산하는 React 웹앱입니다. 두 지점을 차례로 누르는 방식에서 변경했습니다. **새 자동 방식의 실제 휴대폰 동작과 높이 정확도는 미검증**입니다.

앱: https://ruy911-png.github.io/galaxy-height-check/

소스: https://github.com/ruy911-png/galaxy-height-check

## 휴대폰에서 할 일

1. Chrome 앱의 주소창에서 앱을 열고 새로고침합니다. 상단 **v0.3.0**을 확인합니다.
2. **높이 측정 시작**을 누르고 권한을 허용합니다.
3. 가구가 가리지 않는 벽을 향합니다. **위 표시에는 실제 천장, 아래 표시에는 실제 바닥**이 함께 보이게 구도를 잡습니다. 따로 지정 버튼을 누르지 않습니다.
4. 두 표면을 계속 인식하고 높이가 안정되면 약 1초 뒤 m/cm 참고값이 나타납니다. 표면을 놓치면 값은 사라집니다. **다시 읽기**로 새로 계산할 수 있습니다.

빈방일 필요는 없습니다. 문·창이 있는 벽도 구도를 잡는 데 사용할 수 있지만, **문·창의 크기로 방 높이를 추정하지 않습니다.** 표시가 문틀·창틀·가구·유리에 걸리면 올바른 방 높이가 아닐 수 있습니다. 앱은 이 사물들을 자동 구별하지 못합니다. 안전하게 설 수 있는 위치에서 두 실제 면이 한 화면에 들어오지 않으면 이 방식은 사용할 수 없습니다. 카메라를 위아래로 따로 돌려 두 점을 저장하지 않습니다.

## 구현 범위

- 같은 실제 XR 프레임, 세션, `local-floor` 좌표계의 위·아래 plane hit만 사용합니다. `천장.y - 바닥.y`가 높이이고 대각선 거리는 사용하지 않습니다.
- 화면 높이 20%와 80% 위치에 대응하는 광선을 실제 XR 투영 행렬로 계산합니다. 카메라 시야각을 임의로 가정하지 않습니다.
- 가장 가까운 표면만 검사합니다. 가까운 벽·가구를 건너뛰어 먼 천장을 선택하지 않습니다.
- 바닥 후보는 카메라 아래, 천장 후보는 카메라 위에 있어야 하고 두 면 모두 수평에서 20도 이내여야 합니다. 이 조건은 표면의 실제 종류를 보장하지 않습니다.
- 약 1초, 최소 10개 서로 다른 프레임에서 높이가 안정된 뒤에만 참고값을 표시합니다. 안정성 기준은 정확도 보증이나 허용 오차가 아닙니다.
- 한 면 없음, 잘못된 면, 250ms 초과한 위치, 추적 상실, 화면 숨김, 좌표계 변경, 세션 종료는 이전 자동 값을 지웁니다. 가상 평면·시뮬레이션·사진만으로 만든 높이는 없습니다.
- 결과는 AR 화면에 실시간으로 표시됩니다. 종료 후 결과 저장은 아직 제공하지 않습니다. 기존 순차 측정 코드는 회귀 검사 대상으로 남겨 두었지만 기본 화면은 새 방식입니다.
- 영상은 휴대폰에서 처리하며 업로드·로그인·광고·분석 수집·유료 API·외부 런타임 CDN이 없습니다. 카메라는 사용자가 시작할 때만 켜고 마이크 권한을 요청하지 않습니다.
- `local-floor`, `hit-test`, `dom-overlay`가 필요합니다. 별도 진단 화면은 지원 응답·카메라·표면 신호를 구분하며 방 높이 정확도의 증거가 아닙니다.

사용자의 “폴더7”은 우선 Galaxy Z Fold7로 해석했고 One UI 9.0은 사용자 확인 정보입니다. 목표는 대략적인 높이 확인이며 수치 허용 오차에 합의한 것은 아닙니다. 기존 버전에서 실제 AR 카메라와 바닥 지정 뒤 천장 단계 진입을 확인했습니다. 천장 측정 성공과 줄자 비교는 아직 확인되지 않았습니다. 코드 작성·검사는 에이전트가 처리하며 사용자는 설치 명령을 실행할 필요가 없습니다.

## 개발 실행 방법

Node.js 24.22.1 / npm 11.9.0에서 설치·검사합니다. 앱과 개발 의존성 버전은 `package.json`, 간접 의존성은 `package-lock.json`에 고정했습니다.

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run dev
```

`npm run dev`가 표시하는 localhost 주소는 해당 컴퓨터의 개발용입니다. 휴대폰에서 컴퓨터의 일반 `http://192.168…` 주소를 여는 방식은 WebXR의 보안 조건을 충족하지 않습니다. 휴대폰이 신뢰하는 HTTPS 주소로 **최상위 페이지에서 직접** 열어야 합니다. iframe 미리보기는 권한 정책에 따라 거절될 수 있습니다.

프로덕션 파일은 `dist/`에 생성됩니다. HTTPS 정적 호스팅만 필요하며 서버 연산이나 비밀 키는 필요 없습니다. GitHub의 `main`에는 소스, `gh-pages`에는 검증한 정적 빌드가 있습니다. `public/_headers`는 Cloudflare Pages·Netlify 형식이며 GitHub Pages에는 적용되지 않습니다. 공개 HTTPS 응답은 확인했고 실제 휴대폰 카메라·AR 동작은 별도로 확인해야 합니다.

## 남은 확인

실제 갤럭시 Chrome에서 한 화면의 두 표면 인식과 자동 계산을 확인한 뒤, 줄자 기준값과 같은 위치 5회 측정값·실패 횟수를 기록합니다. 실측 결과를 받기 전 정확도는 **미검증**입니다. 자동 테스트 통과는 방 높이의 정확도 검증이 아닙니다.

사용자는 이 저장소의 소스코드 공개 커밋·푸시와 무료 GitHub Pages 공개 배포를 명시적으로 승인했습니다. 추가 공개 대상이나 유료 서비스를 사용하지 않습니다.
