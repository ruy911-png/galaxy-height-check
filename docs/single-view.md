# 한 화면 자동 계산 — v0.3.0

## 사용 조건

가구가 가리지 않는 벽 쪽에서 실제 천장과 바닥을 한 화면에 담습니다. 위 표시(화면 높이 20%)는 천장, 아래 표시(80%)는 바닥에 놓여야 합니다. 두 곳의 실제 AR 위치가 함께 안정되면 수직 높이를 자동 계산합니다. 사용자가 두 점을 차례로 저장할 필요는 없습니다.

문이나 창이 있는 벽을 고르는 것은 가능합니다. 문·창의 표준 크기를 가정하거나 문·창에서 방 높이를 추측하는 기능은 아닙니다. 가구·문틀·창틀은 자동으로 식별하지 못합니다. 수평 문틀이나 침대 윗면은 기하 조건을 통과할 수 있으므로 두 표시가 실제 면에 놓이는지 보아야 합니다. 평평한 바닥과 일정한 높이의 천장을 대상으로 합니다.

방이 좁아 두 면을 동시에 담을 수 없거나, 무늬 없는 천장·유리 반사·역광 때문에 표면 인식이 실패하면 값을 만들지 않습니다. 시작 직후에는 주변 표면을 알아내기 위해 휴대폰을 조금씩 천천히 움직여야 할 수 있습니다. 고정된 사진 한 장만으로 측정하는 기능이 아닙니다.

## 계산과 차단

- 단일 XRView의 실제 투영 행렬을 역변환하고 view→viewer 변환을 적용하여 두 화면 위치에 대응하는 viewer 공간 offsetRay를 만듭니다. 임의 시야각은 쓰지 않습니다.
- 두 hit-test source가 모두 준비된 뒤 같은 실제 XRFrame에서 가장 가까운 plane hit를 각각 읽습니다. 더 먼 수평면을 찾으려고 가까운 벽·잘못된 hit를 건너뛰지 않습니다.
- 두 hit는 동일 timestamp·sessionId·epoch·viewerY를 공유해야 합니다. 좌표는 `local-floor`의 미터 단위이며 높이는 `ceiling.y - floor.y`입니다.
- 기존의 유한 좌표·250ms 신선도·수평 20도·카메라 위/아래 검사를 함께 사용합니다. 추적 중단·숨김·좌표계 reset·세션 종료는 후보를 무효화합니다.
- 최소 1초 및 서로 다른 10개 프레임을 기다립니다. 각 면의 Y가 안정 구간 시작값에서 2.5cm 넘게 움직이면 다시 기다립니다. **이 수치는 관측의 안정성 조건이며 실제 높이 오차가 2.5cm 이내라는 뜻이 아닙니다.**
- 단일 화면 모드는 실제 프레임마다 계산기에 전달합니다. UI 갱신 간격 사이에 생긴 잘못된 면을 놓치고 안정 구간을 이어 가지 않도록 합니다.
- 값은 실시간 참고값입니다. 무표면·기울어진 면·오래된 좌표·재시도에서 즉시 제거하며 결과 저장은 제공하지 않습니다. 가상 평면이나 모의 데이터 fallback은 없습니다.

## 줌·화면 시야 변화

카메라의 투영 행렬이나 viewer 기준 광선이 바뀌면 기존 source를 취소하고 새 광선으로 다시 요청합니다. 재설정 중 이전 값을 표시하지 않고, 새 좌표의 안정 시간을 처음부터 셉니다. 빠르게 여러 번 바뀐 경우 늦게 완료된 이전 요청도 취소합니다.

브라우저의 화면 확대·이동은 카메라 줌과 구분합니다. `visualViewport`의 배율이 1에서 벗어나거나 화면이 이동한 경우 표시 위치가 광선과 맞지 않을 수 있어 계산을 막고 원래 크기로 돌리는 안내를 표시합니다. 좌표 조회 시점에도 검사하며 복구 후 다시 인식합니다.

이 기능은 **WebXR이 알려 주는 카메라 시야 변화 대응**입니다. 앱이 Galaxy WebXR에서 카메라 줌 조작을 지원한다고 보장하는 기능은 아닙니다. 별도 줌 슬라이더나 화면만 늘리는 CSS 확대 기능은 추가하지 않았습니다. 실제 기기에서 줌이 가능한지, 줌 시 투영 정보가 갱신되는지는 아직 확인하지 않았습니다.

## 검증 구분

자동 검사는 합성된 좌표·XR 프레임·투영 행렬 및 모의 AR를 사용하는 React/Chromium 검사입니다. 실제 갤럭시에서 천장이 인식되는지, 두 광선이 카메라 화면의 표시에 맞는지, 실제 줌과 높이 오차는 별도 휴대폰 검사가 필요합니다. 실제 방 높이 정확도는 **미검증**입니다.

초기 수동 방식에서 카메라와 바닥 지정 후 천장 단계 진입은 사용자 사진으로 확인했습니다. 새 한 화면 방식의 실제 성공과 기준 높이 비교는 아직 받지 못했습니다. [5회 기록표](accuracy-record.csv)에 기준값과 측정값·실패를 따로 기록합니다.
