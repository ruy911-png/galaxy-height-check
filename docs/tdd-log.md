# TDD 진행 기록

초기 v0.1의 진단 화면은 먼저 구현하고 테스트를 추가했습니다. 이를 TDD라고 보고하지 않았습니다. 사용자 질문 이후 v0.2 높이 측정 기능은 테스트를 먼저 작성하고 실제 실패를 확인한 다음 구현했습니다. 커밋·푸시는 하지 않았습니다.

## 수직 높이와 측정 상태

파일: `tests/measurement.test.ts`, `src/measurement.ts`.

1. 알려진 좌표와 상태 전환을 검사하는 테스트 16개 작성.
2. 미구현 모듈 import 실패 확인. 이때 테스트 본문은 실행되지 않았으므로 동작 실패 수로 세지 않음.
3. `Not implemented` 예외만 내는 API 골격을 추가하고 같은 검사 실행: **15개 실패, 1개 통과**. 통과한 1개는 잘못된 좌표에서 예외가 발생하는지 검사한 사례.
4. 수직 Y 차이·단위·현재 후보 만료·동일 좌표계·추적 무효화·재측정을 구현: **16개 통과**.

명령: `npm test -- tests/measurement.test.ts`.

예: 두 점의 수직 차이 2.4m, 수평 이격 1.8m이면 대각선은 3m이지만 표시할 높이는 2.4m. 모든 숫자는 합성 테스트 입력이며 실측이 아닙니다.

## 실제 프레임의 좌표와 추적 연속성

파일: `tests/arMeasurementHit.test.ts`, `src/arDiagnostic.ts`.

1. 현재 프레임 위치, 표면 법선, 카메라 높이, 세션 ID, 좌표계 epoch, 출처, 오래된 좌표 차단 등의 테스트 14개를 먼저 작성.
2. **14개 실패**: `diagnostic.getCurrentHit is not a function`. 모의 XR 시작은 정상적으로 실행됐으며 빠진 기능의 호출에서 실패.
3. 실시간 snapshot API 구현 후 **14개 통과**.
4. 검토 중 프레임이 250ms 넘게 멈췄다가 타이머보다 먼저 복구되면 중단을 놓치는 경로 발견. 회귀 테스트를 먼저 추가해 **1개 실패, 14개 통과** 확인. 오류는 `expected 0 to be greater than 0`으로 추적 epoch가 바뀌지 않은 상태.
5. 직전 프레임 시각과의 간격을 먼저 검사하고 동기적으로 무효화하도록 수정: **15개 통과**.

명령: `npm test -- tests/arMeasurementHit.test.ts`.

## 측정 화면

파일: `tests/MeasurementPanel.test.tsx`, `src/MeasurementPanel.tsx`.

1. 측정·결과·재측정·현재 hit 재확인·추적 중단·종료 대기 검사 9개 작성.
2. 컴포넌트 import 실패 확인 후 아무것도 표시하지 않는 골격을 추가.
3. 실제 렌더링 검사 **9개 실패**: `Unable to find an accessible element ... 높이 측정 시작`.
4. 바닥 지정 → 천장 지정 → 결과 → 재측정 화면 구현: **9개 통과**.
5. 검토 중 중단 상태 안내 없이 좌표계만 달라지는 경우 버튼이 계속 비활성화되는 복구 문제 발견. epoch 변경과 session ID 변경의 회귀 테스트 2개를 먼저 추가: **2개 실패, 기존 9개 통과**.
6. 새 hit의 좌표계와 저장한 바닥의 좌표계를 버튼 활성 여부와 관계없이 비교·초기화하도록 수정: **11개 통과**.

명령: `npm test -- tests/MeasurementPanel.test.tsx`.

## 앱 통합과 최종 검사

기존 카메라 미리보기가 측정 시작 전에 종료되고 다른 AR 시작이 차단되는 앱 통합 검사를 먼저 추가했습니다. 구현 전 통합 검사에서는 **6개 실패, 5개 통과**를 확인했습니다. 그중 일부는 진단 overlay 식별자와 안내 문구 변경을 반영하기 전의 계약 실패이며, 새 측정 시작 버튼 부재로도 실패했습니다. 통합 뒤 App 검사 **11개 통과**.

최종 명령: `npm run build`, `npm test`, `npm ls --depth=0`.

**7개 테스트 파일, 69개 검사 통과**, TypeScript·Vite 빌드 통과. 이후 변경은 이 기록과 사용 안내 등 문서에 한정합니다. 하드웨어를 모의한 테스트는 실제 카메라·천장 인식·방 높이 오차를 검증하지 않습니다.
